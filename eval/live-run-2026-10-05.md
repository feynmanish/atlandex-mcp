## Fixes made (all in `src/atlandex_mcp/server.py`, text only, no logic)

1. `find_videos` description and zero-match hint: matching is punctuation-exact ("retrieval-augmented
   generation" 0 hits, "retrieval augmented generation" 3; "self-supervised learning" 2, unhyphenated 0), so
   retry once with hyphens added or removed. The old hint example `'RAG'` matched nothing. (Committed earlier.)
2. Server instructions, round 1: use the tools for "what do people/experts say" questions and YouTube links
   instead of answering from memory; for unsearchable videos say the text cannot be read and cite the chapter
   link from `find_videos`. Fixed Q3 and Q9, not Q1 and Q2.
3. Server instructions, round 2: call `find_videos` first, before answering any AI, tech, business or science
   question about a topic, company or person; if nothing matches, answer normally and say so. Fixed Q1, Q2.
4. `locate_quote` description: it returns only a time, a hit can be approximate, use it only for words already
   known from a passage or the user, never to guess what a speaker said. Fixed Q9.
5. Haiku round: instructions say to copy the `youtube_url` whole, including `&t=...s`, and to say what the
   passages do not cover; the `locate_quote` phrase parameter says "copied as spoken, not keywords or a topic".
   Fixed Haiku Q2 and Q9, not Q10.

## Found but not fixable in this repo

`locate_quote` has false positives. For vIRiUUtSggM it returned `found:true` (3851 s) for "purple elephants
dancing on the moon", and `found:true` for phrases that are not in the captions at all ("I am a skeptic",
"Gartner hype cycle", "peak of inflated expectations"). The server accepts any `match_source` it treats as
located, and the backend reports non-matches as "transcript" too, so the server cannot tell them apart.
The same phrase for aircAruvnKk answered `found:false` once and `found:true` (598 s) twice later. The
real fix is on the backend: `snippet-seek` should return a match quality or report no match. That is outside
this repo, so it is only mitigated here by the description text above.
